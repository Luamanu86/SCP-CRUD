SCP Foundation CRUD Application

Project Description

This project was developed for COMP.5210 Web Application Implementation, Assignment 3.

The application allows users to manage SCP Foundation records using Create, Read, Update and Delete (CRUD) functions.

Technologies Used

PHP

MySQL

HTML5

CSS3

Bootstrap

GitHub

Application Features

CREATE: Add new SCP records.

READ: View SCP subject information.

UPDATE: Edit existing SCP records.

DELETE: Remove SCP records.

Responsive Design: Supports desktop, tablet and mobile screens.

Database

The MySQL database contains 10 SCP records with six fields: ID, Subject, Class, ImageUrl, Description and Containment.

Project Files

index.php — Displays SCP information.

create.php — Adds new SCP records.

update.php — Updates existing records.

connection.php — Connects to the database.

mystyles.css — Website styling.

images/ — SCP subject images.
